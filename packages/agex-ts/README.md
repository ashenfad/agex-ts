# agex-ts

An agent loop over [`@agex-ts/world`](../world): sessions and typed
tasks, with code as the action space. The TypeScript counterpart of
[agex](https://github.com/ashenfad/agex), matching its meaning.

> **Status:** being rewritten on the `rebuild` branch, step by step (the
> repo's `plan.md`, "Then agex-ts"). So far: the run record, the provider
> protocol and a scripted provider, and agex's shape corpus vendored
> (`agex-ts/conformance`). The loop itself comes next. The published
> 0.5.x is the previous design, which this replaces.
